# GitHub Implementations

## 1. SPECTER

**Allen Institute for AI**

[GitHub Repository](https://github.com/allenai/specter)

SPECTER is a scientific-document representation model that uses citation information to generate embeddings for research papers. It can be used for paper similarity, recommendation, and literature discovery.

## 2. S2ORC

**Allen Institute for AI**

[GitHub Repository](https://github.com/allenai/s2orc)

S2ORC (Semantic Scholar Open Research Corpus) is an open scholarly dataset containing research papers, abstracts, references, and full-text information. It can be used to develop and evaluate academic literature-mining systems.

## 3. ASReview

**ASReview Team**

[GitHub Repository](https://github.com/asreview/asreview)

ASReview is an open-source machine-learning framework for screening academic literature. It helps researchers identify relevant studies efficiently during systematic literature reviews.

## 4. SciDocs

**Allen Institute for AI**

[GitHub Repository](https://github.com/allenai/scidocs)

SciDocs is an evaluation framework for scientific document representations. It provides benchmark tasks for testing methods related to scientific-paper similarity, classification, and retrieval.

## 5. OpenAlex

**OurResearch**

[GitHub Repository](https://github.com/ourresearch/OpenAlex)

OpenAlex is an open scholarly knowledge graph containing information about research works, authors, institutions, journals, and citations. It can be used to build and study literature discovery and citation-analysis systems.

## 6. Pyserini

**Castorini Research Group**

[GitHub Repository](https://github.com/castorini/pyserini)

Pyserini is an open-source information-retrieval toolkit for searching and ranking documents. It is relevant to this project because it provides tools for building and evaluating search systems that can be applied to academic literature discovery.
